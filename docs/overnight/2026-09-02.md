## 0.3 The additive-only gate — `scripts/overnight-gate.sh`, baseline in `baseline-hashes.txt`
**The brief's premise here is false at HEAD, and this is the important Stage 0 finding.**

- `artist recompute` **already DIFFERS** on both complete trajectories before I have changed a line:
  `render: recorded 1, recomputed 0.6` on both, plus `hardViolations`, `problemsGrounded`,
  `termination` (`out-of-steps` -> `finish-blocked`), and `judgePending` -> `pendingRubrics`.
- `artist replay` **already refuses**: `NOT COMPARABLE — the environment moved after this run was
  recorded`, on both. Recorded vs now: `observationHash 23da677cea3b / 00f8a7a54e2c -> 199dfe688d5d`,
  `dynamicsHash 9ebbcac19ed1 -> f3902a5da90a`, `positionHash bdb6e5335312 / adc3513be8c1 ->
  67e566914a2c`, `protocolHash e37ae0e46c4c -> 780a090fbde7`, `briefHash 15853c3b5f0f -> 3a44adaf64bb`.

So **"replay is byte-for-byte with the model unplugged, that is your test harness tonight" is not
true.** Replay renders nothing on these dirs; it declines. I did not "fix" that — the refusal is
correct behaviour and the drift predates tonight.

The gate was therefore built to assert the thing that is actually checkable: **nothing already on
disk moves.** It captures (a) sha256 of the protected bytes — `corpus/manifest.jsonl`,
`corpus/clip.f32`, `corpus/clip-index.json`, `aesthetic/holdout.json`, the 5 element-pack JSONs, and
every `scores.json` / `studio.jsonl` / `final.png` / `final.json` in `out/` — and (b) the exact
output text of `recompute` and `replay`, normalised for paths. Because replay prints the current
`now` hashes, **any bump to observationHash / dynamicsHash / positionHash / protocolHash / briefHash
fails the gate**, which is precisely what Rule 12 protects. Runs in **1.2s**, so it is cheap enough
to run before every commit.
